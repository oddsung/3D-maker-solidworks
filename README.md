# 3D-maker-solidworks

도면 PDF 에서 치수를 추출하여 SolidWorks API(COM)로 3D 모델을 자동 생성하는 Python 프로젝트입니다.

## 📁 프로젝트 구조

```
SolidWorks/
├── main.py                  # 메인 프로그램: PDF(여러 장) -> 치수 추출/병합 -> SolidWorks 모델링
├── pdf_dimension_parser.py  # PDF 도면에서 치수 추출 (pdfplumber + 규칙/휴리스틱 + 지시선 벡터 추적)
├── vessel_spec.py           # 용기/노즐 사양 데이터 클래스 (VesselSpec, NozzleSpec), JSON 보정
├── sw_modeler.py            # SolidWorks COM 으로 중공 쉘/경판, 새들, 러그, 노즐 생성
├── drawing_info.py          # 도면 1장 정보 추출 (제목란, 종류/등급, 뷰, 부품표, 마크, 용접선, 라벨 치수, 사실)
├── drawing_set.py           # 도면 세트: 도면 간 연관성, 값 일관성, 누락 값 보완(resolve)
├── analyze_set.py           # 도면 세트 분석 CLI (리포트/JSON 출력, --ai 로 Claude headless 사용)
├── ai_headless.py           # Claude Code headless(`claude -p`) 래퍼: 스캔 도면 읽기, 노즐 값 찾기, 관계 해석
├── asme_flange.py           # ASME B16.5 / B16.47(A·B) Class 300 플랜지 표 (볼트 원, 구멍 수·지름, 두께, 허브)
├── ASME CODE 2025/          # 참고용 ASME 코드 PDF (git 제외)
├── sample_pdf/sample_001/   # 실제 공사 도면 세트 20장 (git 제외, *.pdf)
├── output/<세트명>/         # analyze_set.py 출력 (git 제외)
├── requirements.txt
├── P-SK002-002-ME-490-0001 Rev 2.pdf          # 리프팅 배치도
├── P-SK002-002-ME-490-0002 Rev 3 (1of2).pdf   # GA 1/2 (설계 데이터, 노즐 리스트)
├── P-SK002-002-ME-490-0002 Rev 3 (2of2).pdf   # GA 2/2 (입면도, 단면도)
└── basic_samples/           # SolidWorks API 기초 테스트 스크립트 모음
```

## 🛠 필수 요구사항
- Windows + SOLIDWORKS 설치 (COM 등록: `SLDWORKS.exe /regserver`)
- Python 3.x, `pip install -r requirements.txt`
- 파트 템플릿(.prtdot): 기본 템플릿이 없으면 등록된 템플릿 폴더에서 자동 검색 (MBD 템플릿 포함), 없으면 `--template` 지정

## 🚀 사용법

```bash
# 1) SolidWorks 없이 파싱 결과만 확인
python main.py "P-SK002-002-ME-490-0001 Rev 2.pdf" "P-SK002-002-ME-490-0002 Rev 3 (1of2).pdf" "P-SK002-002-ME-490-0002 Rev 3 (2of2).pdf" --dry-run

# 2) 세 도면을 합쳐 모델 생성 및 저장 (기본 C:\Temp\<도면번호>.SLDPRT, 노즐 54개 포함 약 2~3분)
python main.py "P-SK002-002-ME-490-0001 Rev 2.pdf" "P-SK002-002-ME-490-0002 Rev 3 (1of2).pdf" "P-SK002-002-ME-490-0002 Rev 3 (2of2).pdf"

# 3) 빠른 확인: 노즐 제외 / 일부 노즐만
python main.py … --no-nozzles
python main.py … --only N2,N8,N24 --no-save

# 4) 저장 경로 / 템플릿 지정
python main.py … --out C:/Temp/Vessel.SLDPRT --template "C:/.../Part.prtdot"

# 5) 파싱 값이 틀리거나 누락된 경우 JSON 으로 보정
python main.py … --export-spec spec.json      # 파싱 결과 저장 (노즐 목록 포함)
python main.py … --spec spec.json             # 수정한 값으로 모델링
```

리프팅 도면만 넣으면 이전처럼 O.D 기준 솔리드 형상(두께 없음)으로 만들어지고, GA 도면을 함께 넣으면 두께·경판·노즐이 반영됩니다.
여러 도면의 값이 겹치면 **리프팅 도면 < GA 노즐 리스트 < GA 입면도** 순으로 상세 도면 값이 우선합니다.

```bash
# 6) 공사 도면 세트(폴더) 전체를 넣기: 리프팅/GA 시트를 자동 선택하고 노즐 상세도·전개도로 누락 값을 보완
python main.py --set sample_pdf/sample_001 --dry-run
python main.py --set sample_pdf/sample_001            # 보완된 값으로 모델링
```

## 📐 DXF 입력 (PDF 와 같은 방식)

DWG 에서 변환한 DXF 도 같은 명령으로 읽습니다. 폴더에 DXF 를 넣고 `--set` 또는 `analyze_set.py` 에 그 폴더를 주면 됩니다.
같은 이름의 PDF 와 DXF 가 함께 있으면 DXF 를 씁니다 (문자·치수가 요소로 남아 있어 더 정확).

```bash
pip install ezdxf                                   # DXF 를 읽으려면 필요
python analyze_set.py sample_dxf/sample_dxf_001
python main.py --set sample_dxf/sample_dxf_001      # 모델링까지
```

`dxf_reader.py` 가 모델 공간을 PDF 와 같은 기본 도형(단어·선분·곡선)으로 바꿔 주므로, 도면 해석 규칙과 모델러는 그대로
돌아갑니다. 좌표는 도면 틀을 찾아 A3 기준 페이지로 정규화하고, 블록·치수·폴리선은 구성 요소로 펼치며, 물체선/치수선은
레이어(치수 요소가 몰린 레이어)로, 중심선은 선종류로 가릅니다. 뷰 축척은 시트 축척에서 정확히 계산합니다.

## 📚 도면 세트 분석 (`analyze_set.py`)

공사 도면 전체(리프팅, GA, 명판, 몸체/서포트 상세, 노즐 상세, 외부 부착물, 운송도, 전개도)를 한 폴더에 넣고 다음 세 단계를 수행합니다.

```bash
python analyze_set.py sample_pdf/sample_001                          # 규칙만 (약 100초, AI 없음)
python analyze_set.py sample_pdf/sample_001 --export-spec spec.json  # 보완된 사양 저장 -> main.py --spec
python analyze_set.py sample_pdf/sample_001 --ai scanned             # + 스캔 도면을 Claude headless 로 읽기
python analyze_set.py sample_pdf/sample_001 --ai assist              # + 규칙이 못 채운 노즐 값을 AI 로 시도
python analyze_set.py sample_pdf/sample_001 --ai full                # + AI 관계 해석 (규칙 결과와 비교)
```

1. **도면별 정보 추출** (`drawing_info.py`): 제목란(도면번호·리비전·시트·날짜), 입력 등급(벡터+문자 / 이미지 스캔),
   종류 판별, 뷰 제목과 축척(뷰 영역은 벡터 연결요소로 잡음), 부품표(표 세로선으로 열 구분, 노즐 상세도는 마크 열 포함),
   노즐 마크, 용접선(L.W.L/C.W.L/H.W.L), 단면 표식, 노트, `nnnn TO C.L / T.L` 라벨 치수(어느 뷰에 속하는지), 비교 가능한
   사실(T.L~T.L, 새들 간격, O.D, 중량, 설계 압력 …), 전개도의 마크별 `T.L+` 위치.
2. **도면 간 연관성** (`drawing_set.py`): 같은 도면번호의 시트, GA 노즐 리스트의 `SEE DWG.` → 해당 노즐 상세 시트,
   노즐 마크 공유(GA ↔ 노즐 상세 ↔ 전개도), 용접선 공유(몸체 상세 ↔ 전개도), 단면 표식 → 다른 시트의 VIEW,
   다른 도면 제목 언급, 같은 값 공유/불일치(값 일관성 표).
3. **누락 값 보완 / 교차 검증** (`DrawingSet.resolve`): GA 에서 `SEE DWG.`·추정·기본값이던 노즐 투영을 상세도의
   `TO C.L`(플랜지 면)로 확정하고, 높이 오프셋·목 외경(BOSS Ø)·플랜지 표기·전개도 `T.L+` 위치를 GA 값과 대조해
   **확인/보완/불일치/참고/미해결** 로 판정합니다. 근거는 노즐 표 `비고` 에 남습니다.
   GA 단면도가 "반경 방향 임의 각도" 로 추정한 노즐은 상세 뷰의 표기로 실제 형상을 정합니다:
   - `VESSEL C.L` + 각도(45°) + `W.P` + 세로 `TO C.L` 하나 → **힐사이드 노즐**. W.P(축과 쉘 내면 교점) 높이, 축 각도,
     W.P→플랜지 면 길이(320, 괄호 값 274.9 = 쉘 외면부터)로 축 방향·축 오프셋·투영을 계산 (N31/N31B).
   - 가로 `TO C.L` + 세로 `TO C.L` → **수평 노즐 + 높이 오프셋** (N31A: 90°, −869, 2135).
   - 수직 노즐(0°/180°)의 가로 `TO C.L` → **축의 좌우 오프셋** (N4~N4E 400, N14/N30 381, N16/N23 356 …).
   - **노즐 단면 실루엣**: 상세 뷰의 굵은 물체선을 축 기준 (s, r) 로 읽어 플랜지 → 허브 → 개선 → 보스 계단형 외곽선을
     `NozzleSpec.profile` 에 넣고, 모델러가 균일 목 대신 이 실루엣을 회전합니다 (플랜지 크기는 호칭의 CL300 표준 외경으로 식별,
     서포트 플레이트 등 플랜지보다 큰 부분은 제외). 45° 로 그린 뷰(N31/N31B)는 표준 목+플랜지로 남습니다.

출력은 `output/<폴더명>/drawing_set_report.md`(리포트), `drawing_set.json`(전체 데이터), `ai_calls.jsonl`(AI 호출 기록)입니다.

**AI(Claude headless) 사용 방식**: 로그인된 Claude Code 를 `claude -p --output-format json --json-schema …` 로 불러 구조화 결과를
받습니다(API 키 불필요). 실측(sonnet, `--effort low`): 스캔 도면 1장을 130dpi PNG 로 렌더링해 읽히면 15~25초·$0.14~0.35,
텍스트만 프롬프트에 넣는 노즐 값/관계 해석은 15초·약 $0.3. 전체 벡터 PDF 를 그대로 읽게 하면 수 분·$0.6 이상이라 쓰지 않습니다.
같은 작업의 이전 결과는 `drawing_set.json` 에서 재사용하며 `--ai-refresh` 로 다시 호출합니다. AI 값은 항상 사람 검토 대상입니다.

### JSON 보정 예
```json
{
  "saddle_web_thickness": 250,
  "nozzle_overrides": {
    "N29": {"angle_deg": 90, "offset_y": 600},
    "N31": {"projection": 2135}
  }
}
```
`nozzle_overrides` 는 마크별 부분 수정, `nozzles` 는 목록 전체 교체입니다. 각도는 단면도 표기와 같이 0=TOP, 90, 180=BTM, 270 이며
`offset_y`(위 +)/`offset_z` 로 노즐 축을 용기 중심선에서 평행 이동할 수 있습니다.

## 🔍 추출하는 치수
| 항목 | 출처 | 추출 방법 |
|---|---|---|
| O.D | 리프팅 | `O.D 3748` 패턴 (회전 문자 자동 보정) |
| I.D / 쉘 두께 | GA 2/2 | `I.D 3658` + 인접 `t45` |
| 경판 형식 / 두께 / 내측 반경 | GA 2/2 | `HEMI` 또는 `2:1`/`ELLIP`, `USED TH'K: 27`, I.D/2 근처의 `R1831` |
| T.L~T.L, 새들 간격 / 오프셋 | 공통 | `(T.L TO T.L)`, `(SADDLE TO SADDLE C.L)` 행. 그 바깥 숫자(2285)는 경판 노즐 플랜지 면 위치 |
| 새들 바닥 폭 / 중심선 높이 | GA 2/2 (우선), 리프팅 | `B.C` 근처 숫자(3302), `2117 (FOR FIXED SIDE)` |
| C.O.G / 러그 위치 / 리프팅 중량 | 리프팅 | C.O.G 기준 좌/우 거리(소수 2개 행) + 좌측 T.L~C.O.G, `LIFTING WEIGHT` |
| 노즐 리스트 | GA 1/2 | 마크(범위 전개: N4~N4E, N1/N1A), 수량, 사이즈, 등급, 플랜지 형식, 서비스, 투영, 목 두께 `t53.16`, 목 외경 `Ø300` |
| 노즐 x 위치 | GA 2/2 | 풍선(원)에서 나가는 지시선 벡터를 추적해 끝점 x 를 `T.L+ ####` 라벨과 매칭. 맞닿은 풍선은 같은 위치 |
| 노즐 방향 / 오프셋 | GA 2/2 단면도 | 가로·세로 **일점쇄선 중심선의 교점**을 뷰 중심으로, 같은 높이의 `90°`/`270°` 라벨로 좌우를 정한 뒤 풍선 지시선 끝점을 (높이, 좌우) mm 로 환산. 수직 노즐은 TOP/BTM, 수평 노즐(정립 문자 그룹 `2150 (N24~N24B,…)`)은 90°/270° + 높이 오프셋(`624` 같은 치수로 스냅), 그 외는 임의 각도(예: N31 141.5°). 경판 맨웨이의 `600` 오프셋도 끝 뷰(F-F)와 입면도 중심선으로 위/아래를 판정 |
| 노즐 투영 | GA 2/2 | 노즐 리스트 값 > 단면도 그룹 숫자(`2370 (N9,…)`) > 반경 방향 노즐은 지시선 끝 반경 > 같은 계열 평균 > 기본값(반경+350) |

파서 로그와 노즐 표의 `비고` 열에 각 값의 근거(지시선/추정/기본값)가 표시되므로 `--dry-run` 으로 먼저 확인하세요.

## 🧱 생성되는 형상 (단위 mm, API 는 m)
1. **Shell+Heads** : 외면+내면 프로파일을 한 스케치에 그려 회전 → 속이 빈 용기. 쉘 t45, 반구 경판 t27(내측 R1831). 두께 차이는 3:1 테이퍼로 연결. 두께를 못 찾으면 솔리드
2. **Saddle** : 몸체/서포트 상세도에서 판 구성을 읽으면 베이스 플레이트(폭×축 길이×t) + 웹 플레이트(축 직각, 베이스 위 모서리에서 뿔 점까지 직선인 부채꼴, 뿔 사이는 웨어 플레이트 바깥면 호) + 리브 플레이트(축 방향, `@pitch x n` 위치) + 서포트(웨어) 플레이트(감싸는 각) 로 만들고(`SaddleBase/Web/Rib/Wear_n`), 판 정보가 없으면 예전처럼 ±60° 감싸는 블록 하나를 기본 두께 300으로 돌출. 새들 뷰의 각도 라벨이 둘이면 큰 각(152°)이 웨어 플레이트, 작은 각(140°)이 웹 뿔
3. **LiftingLug_1~4** : 러그 위치마다 TOP 기준 ±45° 에 구멍 있는 판(기본 400×600×t40) — 판은 축 직각 방향
4. **Nozzle_<마크> / Bore_<마크> / BoltHoles_<마크>** : x 위치의 YZ 기준면에서 각도·오프셋을 반영한 단면을 회전 → 상세도 실루엣(`profile`, 뷰가 45° 로 회전해 그려져 있어도 축을 찾아 추출)이 있으면 플랜지/허브/보스 계단형 외곽선을, 없으면 목(외경/두께는 노즐 리스트) + ASME B16.5 CL300 근사 플랜지 디스크를 만들고, 이어서 내경으로 회전 컷하여 쉘 벽 관통. 목의 안쪽 끝은 목 둘레에서 내면이 가장 깊은 곳까지 넣고, 노즐을 다 만든 뒤 용기 내면으로 회전 컷(`InnerTrim`)하여 내면과 같은 높이로 자른다(오프셋 경판 노즐 N8 도 경판을 완전히 관통). 부품표에 BLIND FLANGE 가 있으면 플랜지 RF 면 위에 개스킷 링(`Gasket_<마크>`, RF 지름~보어, 두께 GASKET tX)과 블라인드 원판(`Blind_<마크>`, 플랜지와 같은 표준의 외경·두께)을 붙여 만들고, 플랜지 링 면에 ASME 표의 볼트 원·구멍 수·구멍 지름대로 구멍을 컷(블라인드까지 관통, 구멍이 중심선을 걸치는 straddle 배치). 상세 뷰 문구 `n-SUP'T PLATES (tXxWY)` 또는 부품표 SUPPORT PLATE 가 있으면 지지판(거싯) n 장을 만든다: 목 부착 위치는 치수 문자, 각도는 굵은 사선, 방위각은 같은 글자의 보조 뷰(VIEW "A")의 `30°` 쌍(TOP/BTM 이면 연직 기준, FIXED/SLIDING SIDE 면 고정 새들 쪽 용기 축 기준. 각도 라벨 쌍이 뷰의 어느 쪽에 있는지로 기준에서 돌린 방향도 읽음 — 예: 라벨이 뷰 왼쪽이면 −90°), 길이는 판 모서리가 쉘 외면에 닿는 곳까지 계산. 노즐 축을 포함하는 기울어진 기준면(`SupportPlane_…`)에 평행사변형을 그려 돌출(`Support_<마크>_<방위각>`). 경판 노즐(N8/N15)은 정면 스케치에서 축 방향으로 생성하고 볼트 구멍은 x 오프셋 기준면에 그림

**플랜지 표준 선택 규칙(담당자 조언)**: NPS 24" 까지 ASME B16.5, 26" 부터 B16.47. B16.47 은 Series A(두꺼움)/B(얇음, 일반적) 중 기본 **Series B**, 상세도 부품표에 `SERIES A` 가 있으면 A. 표 값은 `ASME CODE 2025` 폴더의 B16.5-2025 Table 10/11, B16.47-2025 Table 33/39 에서 옮겼고 출처는 `asme_flange.py` 에 적혀 있습니다. 노즐 표의 `볼트구멍` 열(예: `12-Ø25.4`)로 확인할 수 있습니다.

**치수**: 모델에서 도면 값을 바로 확인하고 나중에 고칠 수 있도록 도면에 적힌 값을 그대로 넣습니다. 노즐은 용기 중심선
(경판 노즐은 그 경판의 T.L) 기준 투영과 축 오프셋, 플랜지 외경, 목 외경, 보어. 지지판은 길이와 폭, 새들은 베이스 폭과
두께, 쉘은 외경·내경과 T.L 길이입니다. 지름은 도면처럼 **Ø 값**으로 들어갑니다(중심선을 기준으로 잡고 `Diametric` 을
켜면 반지름이 아니라 지름이 됩니다). 투영에는 도면과 같이 `TO C.L` 이 붙고, 치수마다 이름(`N9_PROJ`, `SHELL_OD` 등)을
붙여 값과 같이 보이게 합니다. 만든 직후 값을 되읽어 도면 값과 다르면 콘솔에 경고하고, 빌드 끝에 `이름 = 값` 목록을
출력합니다.

**완전 정의**: 스케치는 완전 정의 상태로 남습니다. 도면 치수를 넣은 스케치는 SolidWorks 의 자동 완전 정의로 기하 구속과
모자란 치수를 채웁니다. 도면 치수는 그대로 남고 자동으로 붙는 치수도 모두 구동 치수라, 완전 정의와 편집 가능이 함께
됩니다(사내 담당자가 손으로 하던 방식과 같습니다). 자동 완전 정의는 움직이지 않는 기준점이 있어야 동작하므로 스케치마다
원점에 고정 점을 하나 둡니다. 편집할 값이 없는 보조 스케치(리브, 볼트 구멍 등)는 고정 구속으로 완전 정의합니다. 자동 완전
정의와 고정 구속을 함께 쓰면 과정의가 되므로 한 스케치에는 둘 중 하나만 씁니다.

**화면**: 피처가 생길 때마다 솔리드 범위만 보고 화면을 맞춰(`ViewZoomTo2`) 모델이 항상 가운데 보이게 합니다.
`ViewZoomtofit2` 는 치수선·주석까지 화면에 넣으려 해서 치수를 붙일수록 모델이 작아집니다. 스케치를 열 때 시점이 그
평면 정면으로 돌아가는 설정도 꺼 두었다가 끝나면 원래대로 되돌립니다.

도면에 없는 값(새들 두께, 러그 크기, `SEE DWG.` 투영 등)은 `vessel_spec.py` 의 기본값을 쓰고 `--spec` JSON 으로 바꿀 수 있습니다.

## 💾 저장 관련
- SolidWorks 는 같은 파일명의 문서를 두 개 열 수 없으므로, 저장 대상 파일이 이미 열려 있으면 빌드 시작 전에 `<이름>_<HHMMSS>.SLDPRT` 로 바꿔 저장합니다 (콘솔에 안내).
- 저장에 실패해도 모델은 SolidWorks 에 열려 있으니 수동으로 다른 이름으로 저장하면 됩니다.
